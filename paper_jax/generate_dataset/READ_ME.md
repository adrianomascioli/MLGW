# Generating the dataset

This directory contains the python script and the shell command used to generate the dataset for the training of the model over SEOBNRv5HM. The pyseobnr package is currently only compatible with python3.9. For this reason we did not implement an interface inside MLGW, but we used this python script (largely inspired by `MLGW/bin/generate_dataset`) in a dedicated conda environment.
